Playground

Escribí cualquier programa en C#, con todas las clases que quieras (una por pestaña), ejecutalo o miralo paso a paso. También podés conectarte a la base tienda con ADO.NET o Entity Framework.

En tu compu

Cómo seguir practicando fuera de esta página

  • Instalá Visual Studio 2022 Community (gratis) con la carga de trabajo «Desarrollo de ASP.NET y web» o «Desarrollo de escritorio de .NET». Creá un proyecto «Aplicación de consola», pegá cada clase en su archivo (clic derecho en el proyecto → Agregar → Clase) y ejecutá con F5. También sirve VS Code con el SDK de .NET 8.
  • Para la base de datos: MySQL Server + MySQL Workbench con la base tienda (o SQL Server con SSMS), y desde Administrar paquetes NuGet instalá MySql.Data para ADO.NET, o Microsoft.EntityFrameworkCore + Pomelo.EntityFrameworkCore.MySql para Entity Framework.
  • Este editor ejecuta C# con un intérprete propio dentro del navegador: compila con las mismas reglas (tipos, accesos, override, códigos de error CS) y los resultados coinciden con .NET 8. La base de datos es simulada y vuelve a su estado original en cada ejecución.
  • Una diferencia: con Windows en español, .NET muestra los decimales con coma (3,14) y double.Parse espera la coma. Este editor usa siempre el punto y acepta las dos formas al leer.

Examen de prueba

Mezcla preguntas de opción múltiple y programas para escribir. Los programas se corrigen solos: se ejecutan con distintas entradas y se compara lo que muestran. Al final ves tu nota y la resolución de lo que erraste.
